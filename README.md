# C& — C with Ownership

> **Keep C. Add ownership.**

C& (pronounced **“C and”**) is a compile-time safety layer for C. It adds an explicit ownership and borrowing model to ordinary C development **without creating a new C compiler, forking Clang/GCC, defining a new ABI, or replacing the existing native toolchain**.

The full project baseline, ADRs, SPECs, contracts, compatibility fixtures, contribution policy and CI are being established in this initial `main` commit.
